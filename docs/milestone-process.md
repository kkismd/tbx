# マイルストーン完了時のクイックリファレンス確認

TBX または TBX Next のマイルストーンを完了する前に、そのマイルストーンで追加・変更したユーザー向け構文、標準語彙、入出力、CLI、実行方法、主要な注意事項が対象クイックリファレンスに反映されているか確認する。

対象は現行 TBX が [`tbx-quickref.ja.md`](tbx-quickref.ja.md)、TBX Next が [`next/tbx-quickref.ja.md`](next/tbx-quickref.ja.md)。実装・テスト・ADR・仕様を正本とし、クイックリファレンスは実装済み内容の実用的な入口として扱う。

## 計画と更新

- マイルストーンを新規作成または再整理するときは、原則として最後にクイックリファレンスとの整合性を確認し、必要なら更新する文書整備 issue を配置する。
- 未反映の内容があれば、原則としてマイルストーン内の最後の実装 issue でクイックリファレンスを更新する。
- 各機能 issue で毎回更新することは原則必須としない。同一マイルストーン内で仕様や実装が変化する間に記述が繰り返し揺れるのを避け、最後にまとめて確認するためである。ただし、途中で明らかな誤情報になる場合など、早期更新が必要なときは個別 issue で対応し、その影響を記録する。

## 完了記録

変更が不要な場合も、確認済みであることを milestone issue など完了状況を追跡できる場所に記録する。
